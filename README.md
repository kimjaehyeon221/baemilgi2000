# PUSH TOTAL

오늘 한 푸쉬업을 기록하면 평생 누적 개수를 계속 더해주는 iPhone 앱입니다.

## 제품 원칙

- 홈의 주인공은 **평생 누적 숫자**
- 입력은 `+10`, `+20`, `+50`, 직접 입력
- 스트릭, 칼로리, AI 코치, 소셜, 리더보드 없음
- 기록은 기기에만 저장
- 로그인/계정 없음
- 기록 내보내기 지원

## 현재 상태

이 앱은 `pushup-total` 브랜치에서 독립적으로 개발합니다. 아직 Expo EAS 프로젝트에는 연결하지 않았습니다. Apple Developer 멤버십이 활성화되면 별도 Expo 프로젝트로 연결하고 TestFlight 빌드를 만듭니다.

## 실행

```bash
npm install
npx expo start
```
