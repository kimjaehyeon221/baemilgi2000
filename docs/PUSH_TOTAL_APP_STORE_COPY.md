### Description
**푸쉬업도 걸음처럼 쌓이게.**

PUSH TOTAL은 복잡한 운동 프로그램이 아니라 푸쉬업 하나를 오래 기록하기 위한 가벼운 카운터입니다.

Pocket Count를 누르고 iPhone을 앞주머니에 넣으면 동작 센서가 반복 움직임을 감지해 푸쉬업 횟수를 추정합니다. 마지막 반복 이후 움직임이 멈추면 세트가 자동 저장되고, 오늘 한 푸쉬업과 평생 누적 푸쉬업이 바로 올라갑니다.

주요 기능
- 앞주머니 동작 센서를 이용한 Pocket Count
- 평생 누적 푸쉬업과 오늘 기록
- 이번 주 / 이번 달 / 최근 7일 기록
- 빠른 직접 기록
- 잘못 센 기록 수정 및 삭제
- Pocket Count 민감도 조정
- 전체 기록 내보내기
- 계정 없이 로컬 저장

PUSH TOTAL은 카메라를 사용하지 않습니다. 원본 동작 센서 데이터는 서버로 전송하거나 보관하지 않습니다.

Pocket Count는 기기 위치, 주머니 형태, 운동 속도와 자세에 따라 오차가 생길 수 있으며 모든 세트는 기록 화면에서 직접 수정할 수 있습니다.

## English

### Name
PUSH TOTAL

### Subtitle
Your push-up pedometer

### Promotional text
Put your iPhone in your front pocket and push. Small sets throughout the day become one lifetime total.

### Description
**Let push-ups add up like steps.**

PUSH TOTAL is a lightweight counter built around one exercise and one meaningful number: your lifetime push-ups.

Tap Pocket Count, place your iPhone in a front pants pocket, and start your set. On-device motion sensing estimates repetitive push-up movement. When the set stops, the count is saved into your daily and lifetime totals.

Features
- Pocket Count using iPhone motion sensors
- Lifetime and daily push-up totals
- Week, month, and seven-day history
- Fast manual logging
- Edit or delete incorrect counts
- Adjustable Pocket Count sensitivity
- Record export
- Local storage with no account required

PUSH TOTAL does not use the camera. Raw motion samples are not uploaded or retained on a server.

Pocket Count is an estimate and can vary with pocket placement, cadence, device position, and form. Every set can be corrected from History.

## App Review notes
PUSH TOTAL uses iPhone motion sensor samples during an explicitly started Pocket Count session to estimate repetitive push-up movement. Motion samples are processed live on-device and are not uploaded or retained. Users can correct the estimated count from History. If Motion & Fitness permission is declined, the app remains fully usable with manual logging.
