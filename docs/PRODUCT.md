# Product thesis — PUSH TOTAL

## 한 문장

푸쉬업 한 만큼 기록하세요. 우리는 계속 더해드립니다.

## 핵심 행동

푸쉬업을 했다 → 앱을 연다 → 숫자를 추가한다 → 평생 누적 숫자가 커진다.

## 홈 계층

1. Lifetime total
2. Today
3. Quick add
4. 직접 입력
5. 기록 화면

## 유지해야 할 제약

- 스트릭 금지: 하루를 놓쳤다는 죄책감으로 붙잡지 않는다.
- 운동 계획 앱으로 확장하지 않는다.
- 카메라/자동 카운팅을 넣지 않는다.
- 세션 시간을 늘리는 것이 목표가 아니다.
- 5~10초 안에 기록하고 앱을 닫을 수 있어야 한다.

## App Store 최소 기능성 대응

홈은 단순하지만 뒤에 실제 기록 관리 기능을 둔다.

- 일별 기록 이력
- 최근 7일 시각화
- 이번 주/이번 달 합계
- 자연스러운 장기 마일스톤
- 마지막 입력 취소
- 기존 누적 기록에서 시작 가능
- CSV 형식 텍스트 내보내기

앱의 가치는 화면 수가 아니라 장기간 쌓이는 개인 운동 기록에 있다.
