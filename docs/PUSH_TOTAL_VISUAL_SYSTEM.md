# PUSH TOTAL Visual System — Release Direction

## Style: Flat Industrial / Masonry

PUSH TOTAL should feel like a compact training instrument, not a game ad.

- Background: warm ivory `#F9F7F2`
- Primary ink: near-black `#121212`
- Brick: muted terracotta `#A64B35`
- Dark brick: `#873420`
- Secondary surfaces: warm gray `#F0EEE9` / `#E4E2DD`
- Typography: bold condensed/utility feel; minimal decoration
- Motion: short, mechanical, impact-driven. No cartoon bounce.
- Launch intro target: 1.0–1.2 s total. Flat outlined fist, 6–10 brick fragments, one impact flash, minimal dust, then PUSH TOTAL wordmark/home reveal.
- Avoid: photoreal muscles, glossy 3D bricks, comic explosions, excessive particles, forced workout cadence sounds.

## Sound behavior

- One start cue after the pocket countdown.
- No cadence metronome. The user controls push-up speed.
- Session ends when meaningful phone motion has remained below the stationary threshold for 5 continuous seconds after at least one rep.

## Camera mode

Camera counting is a post-launch accuracy mode, not a launch blocker. Pocket Count remains the default interaction for v0.9.
