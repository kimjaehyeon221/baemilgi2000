## 한국어 제품 페이지 문구

### 이름

배밀기 2000

### 부제

직접 측정하고 쌓는 배밀기 훈련

### 프로모션 문구

현재 가능한 배밀기 횟수를 직접 측정하고, 바로 다음 퀘스트부터 한 단계씩 이어가세요. 운동 기록은 현재 iPhone에 저장됩니다.

### 설명

배밀기 2000은 현재 가능한 배밀기 횟수를 직접 측정한 뒤, 그 기록 바로 다음 단계부터 200개의 퀘스트를 이어가는 간결한 맨몸운동 훈련 기록 앱입니다.

앱이 횟수를 자동으로 세거나 임의의 기록을 만들지 않습니다. 사용자가 같은 자세를 기준으로 직접 센 횟수를 기록하고, 성공뿐 아니라 멈춘 지점도 수련 기록으로 남깁니다.

주요 기능

- 직접 측정한 배밀기 최고 기록에서 시작
- 현재 기록 바로 다음 퀘스트 목표 확인
- 목표를 보며 직접 횟수를 세는 Challenge
- 현재 수준에 맞춘 세트·반복·휴식 Training
- 성공과 중단 기록을 함께 남기는 Training Log
- 계정 없이 바로 사용
- 운동 기록은 현재 iPhone에 로컬 저장
- JSON 백업 내보내기와 복원 지원

마지막 2,000회는 운동 권장량이 아니라 Great Gama의 1911년 Dand 기록에서 가져온 상징적인 최종 퀘스트입니다. 몸 상태에 맞춰 천천히 진행하세요.

배밀기 2000은 의료 진단이나 치료를 제공하지 않습니다. 통증, 어지럼 또는 불편함이 있다면 운동을 중단하고 필요한 경우 전문가와 상담하세요.

## TestFlight — 테스트할 내용

최초 실행부터 자세 확인, 기초 기록 측정, 다음 퀘스트 확인, Challenge 성공/중단, Training 완료, 기록 편집·삭제, 백업·복원까지 전체 흐름을 확인한다.

특히 다음을 확인한다.

- 빈 입력에 임의의 숫자가 들어가지 않는가
- 앱을 종료한 뒤 다시 열어도 기록이 유지되는가
- 백그라운드에 갔다 돌아와도 Baseline/Challenge/Training/Rest 시간이 실제 경과시간과 맞는가
- 미래 퀘스트를 건너뛰어 시작할 수 없는가
- Training 기록이 목표 숫자가 아니라 실제 `세트×반복`으로 남는가
- 잘못된 JSON 또는 다른 앱의 백업이 복원되지 않는가
- 개인정보 처리방침과 지원 링크가 실제 Safari에서 열리는가

## 앱 심사 메모

이 앱은 로그인이 필요하지 않습니다. 사용자가 입력한 배밀기 운동 기록과 설정은 현재 사용하는 iPhone의 앱 저장공간에 저장됩니다. 서버 계정, 광고, 결제, 위치 정보, HealthKit 연동 기능은 없습니다.

최초 실행 시 사용자가 직접 센 배밀기 최고 기록을 입력하면 그 바로 다음 단계부터 퀘스트를 안내합니다. Challenge 화면은 목표만 보여주며 자동으로 반복 횟수를 감지하거나 세지 않습니다.

마지막 2,000회는 운동 처방이나 권장량이 아니라 1911년에 기록된 Great Gama의 Dand 고반복 수행에서 가져온 상징적 끝점입니다. 앱은 의료 서비스가 아니며 의료적 판단을 제공하지 않습니다.

## App Store 스크린샷

Apple의 현재 iPhone 규격 중 6.9인치용 허용 세로 크기로 우선 제작한다. 1~10장을 업로드할 수 있으며, 1.0에서는 실제 사용 흐름을 전달하는 5장을 권장한다.

권장 5장 구성:

1. Home — 현재 다음 퀘스트와 Current Best
2. Active Challenge — 거대한 TARGET과 최소한의 조작
3. Cleared — 절제된 `CLEARED` 스탬프 피드백
4. Training — 세트·반복·휴식 구조
5. Archive — 성공/중단/훈련이 누적되는 Training Log

원칙:

- 실제 앱 화면과 다른 숫자·기능·가짜 지표를 넣지 않는다.
- 자동 카운팅처럼 오해될 `CURRENT COUNT` 표현을 쓰지 않는다.
- Streak, 칼로리, 심박, 속도 등 앱이 측정하지 않는 지표를 넣지 않는다.
- 알파 채널/투명 스크린샷을 사용하지 않는다.
- 제출 직전 Apple의 최신 스크린샷 사양을 다시 확인한다.
