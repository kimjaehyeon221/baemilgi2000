- 데이터 수집: 수집하지 않음

- 연결 빌드: 1.0.0 (6)

## 한국어 제품 페이지 문구

### 이름

배밀기 2000

### 부제

직접 측정하고 쌓아가는 배밀기 습관

### 프로모션 문구

내 몸의 현재 능력을 직접 측정하고, 무리하지 않는 목표로 오늘의 배밀기를 시작하세요. 기록은 기기에 안전하게 보관됩니다.

### 설명

배밀기 2000은 현재의 기초 체력을 직접 측정한 뒤, 나에게 맞는 배밀기 목표를 시작할 수 있도록 돕는 간결한 운동 기록 앱입니다.

임의의 숫자를 대신 넣지 않습니다. 먼저 직접 푸쉬업 능력을 측정하고 기록하면 그 결과를 기준으로 목표를 확인할 수 있습니다.

주요 기능

- 직접 측정한 기초 체력으로 시작
- 오늘의 배밀기 목표 확인
- 운동 완료 기록 저장
- 누적 기록과 진행 상황 확인
- 계정 없이 바로 사용
- 인터넷 연결 없이도 사용 가능
- 운동 기록은 사용자의 기기에만 저장

배밀기 2000은 의료 진단이나 치료를 제공하지 않습니다. 통증이나 불편함이 있다면 운동을 중단하고 전문가와 상담하세요.

### 키워드

배밀기,푸쉬업,팔굽혀펴기,홈트,운동기록,기초체력,맨몸운동,습관,루틴

### 지원 URL

공개 지원 페이지 배포 후 입력한다.

### 마케팅 URL

## 앱 심사 메모

이 앱은 로그인이 필요하지 않습니다. 모든 운동 기록과 설정은 사용자의 기기에만 저장됩니다. 서버 계정, 광고, 결제, 위치 정보, 건강 데이터 연동 기능은 없습니다.

최초 실행 시 사용자가 직접 입력한 푸쉬업 측정값을 바탕으로 운동 목표를 안내합니다. 앱은 의료 서비스가 아니며 의료적 판단을 제공하지 않습니다.

### 처리하는 정보

사용자가 입력한 운동 측정값, 운동 기록 및 앱 설정은 사용자의 기기에만 저장됩니다. 개발자는 이 정보에 접근하거나 이를 수집하지 않습니다.

### 계정

배밀기 2000은 회원가입이나 로그인을 요구하지 않습니다.

### 제3자 제공 및 추적

개인정보를 제3자에게 판매하거나 제공하지 않습니다. 광고 목적의 추적 기능과 제3자 분석 SDK를 사용하지 않습니다.

### 데이터 삭제

기기에 저장된 데이터는 앱을 삭제하면 함께 제거됩니다. 앱에서 제공하는 초기화 기능이 있는 경우 해당 기능으로도 삭제할 수 있습니다.

### 아동의 개인정보

앱은 아동의 개인정보를 의도적으로 수집하지 않습니다.

### 방침 변경

기능 변경으로 개인정보 처리 방식이 달라지는 경우 이 방침을 업데이트하고 시행일을 변경합니다.

자주 묻는 질문

### 기록은 어디에 저장되나요?

운동 기록과 설정은 현재 사용하는 iPhone에 저장됩니다. 계정이나 클라우드 서버로 전송되지 않습니다.

### 앱을 삭제하면 기록도 삭제되나요?

네. 앱을 삭제하면 기기에 저장된 기록도 삭제될 수 있습니다.

### 로그인이 필요한가요?

아니요. 배밀기 2000은 로그인 없이 바로 사용할 수 있습니다.

### 의료 앱인가요?

아니요. 일반적인 운동 습관과 기록을 돕는 앱이며 의료 진단이나 치료를 제공하지 않습니다.
