푸쉬업 기록

평생 누적 횟수와 개별 세트 기록은 사용자의 iPhone 로컬 저장소에만 저장됩니다. 사용자가 앱에서 삭제하거나 앱을 제거하기 전까지 기기에 남으며, 내보내기 기능을 직접 실행한 경우에만 사용자가 선택한 공유 대상으로 전달됩니다.

제3자 서비스

현재 버전에는 광고, 분석, 사용자 계정 또는 제3자 데이터 수집 SDK가 포함되어 있지 않습니다.

보관 및 삭제

기록 화면에서 개별 기록을 수정·삭제하거나 모든 앱 기록을 삭제할 수 있습니다. PUSH TOTAL은 서버 데이터베이스나 사용자 계정을 운영하지 않으므로 원격에서 삭제해야 할 계정 데이터가 없습니다.

권한

동작 및 피트니스 권한은 사용자가 Pocket Count를 선택한 순간에만 요청합니다. 권한을 허용하지 않아도 직접 기록 기능은 사용할 수 있습니다.
